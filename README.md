# Service Desk Ticket Triage & SLA Monitoring Workflow

Scope

This is a beginner portfolio simulation using Excel and documentation. It is not a live ServiceNow implementation. All sample records and SLA targets are fictional/illustrative.

Files

* ServiceNow_Ticket_Triage_Workbook.xlsx: Summary, Ticket Tracker, Triage Rules, Test Cases.
* ServiceNow_Ticket_Triage_Project_Report.docx: workflow, assumptions, scenarios, tests, limitations, and next steps.

How to use

1. Open the workbook in Excel or a compatible spreadsheet app.
2. Go to Ticket Tracker and edit fictional values in Impact, Urgency, Status, SLA Target, and Hours Open.
3. Observe the Priority and SLA Status formulas.
4. Review Triage Rules for the decision logic.
5. Use Test Cases to record observed results and pass/fail.
6. Review the Summary sheet for sample counts.

Important limitations

* Does not create records in ServiceNow.
* Does not send real notifications or enforce approvals.
* Hours Open are manually entered.
* SLA targets are illustrative and are not a real company’s policy.
* Do not claim simulated metrics are measured operational improvements.
